# GAT Countdown ⏱

Ein eleganter, Live-Countdown zum **01. März 2031 um 08:00 Uhr** (Deutsche Zeit).

Zeigt an: **Tage | Stunden | Minuten | Sekunden**

## 🚀 Schnell starten (GitHub Pages)

### 1. Repository erstellen
```bash
git init gat-countdown
cd gat-countdown
git config user.name "Dein Name"
git config user.email "deine.email@example.com"
```

### 2. Dateien hinzufügen
- `index.html` (bereits vorhanden)
- `README.md` (diese Datei)

### 3. Zu GitHub pushen
```bash
git add .
git commit -m "Initial commit: GAT Countdown"
git remote add origin https://github.com/DEIN-USERNAME/gat-countdown.git
git branch -M main
git push -u origin main
```

### 4. GitHub Pages aktivieren
1. Gehe zu deinem Repository auf GitHub
2. Navigiere zu **Settings** > **Pages**
3. Wähle unter "Source" den Branch `main` aus
4. Speichern
5. Nach ca. 1-2 Minuten ist die App unter `https://DEIN-USERNAME.github.io/gat-countdown/` erreichbar

## ⚙️ Anpassungen
Die Datei ist komplett in `index.html` - einfach bearbeiten und neu pushen:
- **Zieldatum ändern**: Suche nach `2031-03-01T08:00:00` und ändere das Datum
- **Farben ändern**: Die CSS-Variablen am Anfang anpassen
- **Text ändern**: "GAT Countdown" etc.
